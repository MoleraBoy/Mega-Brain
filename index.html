📲 Instalar como Aplicativo

No Samsung Internet (Android):
  1. Toque no ícone de seta para baixo (↓) na barra de endereço superior, ou abra o menu (≡) no canto inferior direito.
  2. Toque em Adicionar página a → Tela inicial (ou Instalar aplicativo).
  3. Toque no sino (🔔) no topo do Mega Brain → Ativar Agora para receber notificações na barra do Android!
No Google Chrome (Android / PC):

Toque nos três pontinhos (⋮) → Adicionar à tela inicial / Instalar aplicativo.
