# Projeto Página Única (One-Page)

Estrutura plana sem subpastas, contendo todos os arquivos diretamente na raiz:

- `index.html`: Estrutura semântica da página única (Navbar, Hero, Recursos, Sobre, Contato e Rodapé).
- `style.css`: Estilização moderna com variáveis CSS, grid responsivo e suporte a dispositivos móveis.
- `script.js`: Interatividade para navegação mobile, atualização automática do ano e validação/envio do formulário.
