# Mega Brain - Hub Pessoal & Segundo Cérebro

Estrutura de **pasta única (plana)** sem subpastas, pronta para rodar diretamente no navegador (`index.html`) ou hospedar em qualquer servidor estático.

## Arquivos na raiz
- `index.html`: Interface principal do Hub Pessoal.
- `styles.css`: Estilização e tema escuro responsivo.
- `brain-engine.js`: Motor de aprendizado incremental de tags (tokenização, pesos TF, co-ocorrência e sugestões em tempo real).
- `vault-security.js`: Gerenciamento de pastas privadas e autenticação por PIN com hash SHA-256 (Web Crypto API).
- `storage.js`: Persistência unificada em `localStorage`.
- `app.js`: Controlador principal da aplicação.
- `manifest.json`: Manifesto PWA com caminhos planos.
